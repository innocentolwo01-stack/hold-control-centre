# Hold merchandising upgrade

This upgrade adds the visual reward-management layer required for the Hold app:

- direct Supabase Storage image uploads
- partner logos, square logos, banners, brand colours and descriptions
- reward card, thumbnail and hero artwork
- customer-facing short copy, full descriptions, terms and CTA labels
- merchandising sections, display order, badges and sponsored labels
- campaign creation, scheduling and targeting
- campaign-to-reward placement management

The database migration and `hold-assets` Storage bucket are already active in the connected Supabase project.
